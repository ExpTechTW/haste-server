# Paste URLs are 8 random base62 characters and are never linked from anywhere,
# so nothing here is reachable by crawling in the first place. What matters is
# that a link someone shares can still be unfurled into a preview, and that
# needs the crawlers which generate those previews to be let in.
#
# Keeping pastes out of search results is a separate job, done by the
# `X-Robots-Tag: noindex` header on every paste response — the header can say
# "fetch this, but do not index it", which robots.txt has no way to express.
